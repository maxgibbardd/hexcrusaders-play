# HexCrusaders — playable build

A 3D hex-grid strategy board game built in Unity (URP), with procedural mesh
generation and a faceted low-poly art style.

**Play it: https://maxgibbardd.github.io/hexcrusaders-play/**

Hot-seat for 2–4 players. Full gameplay loop: snake-draft opening placement,
dice-driven resource production, roads/settlements/cities with the distance and
connectivity rules, the robber and discards, development cards, bank/port and
player-to-player trading, longest road, largest army, and a race to 10 victory points.

Controls: left-click the board to build, right-drag to orbit, scroll to zoom.

This repository holds only the compiled WebGL build. Source lives in a separate
private repository.
